Cost Cards

Financial expense tracking components

These cards represent individual cost entries within Costsheets, supporting expense management workflows with approval tracking. Each variant displays the cost value prominently with status badges (DRAFT, IN_APPROVAL, APPROVED, FINAL), parent Costsheet reference, and associated Case context for traceability.
