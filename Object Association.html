Object Association Cards

Cross-object relationships and links

These cards represent associations linking different objects in ArkCase. Each variant shows source and target objects, relationship types, and connection metadata. Association types from the data model include: OWNERSHIP, REFERENCE, SUB_COMPANY, PARENT_COMPANY, and MERGED_TO.

Small Card Specifications

  • Layout: Horizontal flex with icon (w-10), content area, and metadata column
  • Required Elements: Link icon, association type label, source→target reference, status badge, timestamp
  • Optional Elements: Description preview, creator avatar, direction indicator (arrow-right or arrows-left-right)
  • Association Types: OWNERSHIP, REFERENCE, SUB_COMPANY, PARENT_COMPANY, MERGED_TO
  • Interactions: Entire card clickable, hover shadow
  • Context: Association lists, related objects panels, search results

Object Association — Chatbot Cards

Adaptive cards optimized for AI assistant responses (~350px width)

Chatbot Integration: These cards display object-to-object relationships. Features AI-powered relationship explanations, navigation between linked objects, and triple action types: Explanation (understand meaning), Navigation (jump between objects), and Graph View (visualize connections).
