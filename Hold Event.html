Hold Event Cards

FOIA request hold tracking and compliance

Hold Events track when FOIA requests enter or exit the Hold queue. Each event records the hold reason (Unperfected, Tolling, or Fee Assessment), calculates business days on hold, and supports DOJ compliance reporting.

Hold Event Types Reference

Event types from HoldEventType enum

ADDED_TO_HOLD

HoldEventType.ADDED_TO_HOLD

Request entered the Hold queue. Response deadline clock stops.

REMOVED_FROM_HOLD

HoldEventType.REMOVED_FROM_HOLD

Request exited the Hold queue. Response deadline clock resumes.

Hold Reasons Reference

Stored in HoldEvent.reason field - determines DOJ metric calculations

Unperfected

Request is incomplete or needs clarification from requester.

Not counted in DOJ Throughput Metrics

Tolling

Official clock stop per legal or regulatory requirements.

Counted in DOJ Throughput Metrics

Fee Assessment

Awaiting fee payment from requester (costs exceed threshold).

Counted in DOJ Throughput Metrics
